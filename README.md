Requirements, GRASP-based design and architecture of an ATM system for a bank, documented in the repository wiki.

## About

Course project for Systems Development II at Universidade Presbiteriana Mackenzie
(2024, first semester). The system lets customers withdraw, deposit and run other
operations at ATMs in the bank's branches, reducing manual work at the counter. The
team went from the business scenario to the system architecture. The documentation is
in Portuguese.

The banking domain was later implemented as a Spring Boot and Next.js application in
[cyberbank](https://github.com/EnzoFerroni/cyberbank).
